# Smoothie 字幕工具

Smoothie 字幕工具（v4）的公開發佈與自動更新檔案。

- 下載安裝檔：請到本倉庫的 [Releases](https://github.com/ShaoRouRou/purple-smoothie-v4-releases/releases) 頁面，一般使用者只需要下載 `.dmg`。
- `appcast.xml`：App 內自動更新使用的更新資訊檔，已用發佈者的金鑰簽章。

這個 App 原名 purple-smoothie。倉庫名稱與 App 內部識別碼（`com.shaorourou.purple-smoothie`）維持不變，已安裝的 App 才能繼續收到更新。
